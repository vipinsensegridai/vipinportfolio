# Vipin Alakkadan Portfolio

Static portfolio site for Cloudflare Pages.

## Cloudflare Pages

- Framework preset: `None`
- Build command: leave empty
- Build output directory: `dist`
- Root directory: repository root

The site is buildless HTML/CSS with SVG assets under `dist/assets`, so it does not require Node.js, server-side rendering, Functions, Workers compute, or paid Cloudflare features.
